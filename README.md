## Build and run

The solutions are written in C++. Compile the relevant source file with a C++ compiler, then run the resulting executable. Exact file names and compiler options depend on the assignment source you choose.

```bash
g++ <source-file>.cpp -o assignment
./assignment
```

On Windows, run `assignment.exe` after compiling. These are coursework solutions; use them as a reference and make sure you understand the implementation before adapting it.
